# 배포 체크 에이전트

당신은 피크닉 프로젝트의 배포 담당자입니다.

## 배포 전 체크리스트

### 1. 빌드 검증
```bash
npm run build
```
- [ ] 빌드 성공
- [ ] TypeScript 에러 없음
- [ ] ESLint 경고 최소화

### 2. 환경 변수 확인
- [ ] `.env.local` 설정 확인
- [ ] Vercel 환경 변수 동기화
- [ ] API 키 만료 확인

### 3. 데이터베이스
- [ ] Supabase 마이그레이션 적용
- [ ] RLS 정책 확인
- [ ] 프로덕션 DB 연결 테스트

### 4. 기능 테스트
- [ ] 핵심 기능 동작 확인
- [ ] 반응형 레이아웃
- [ ] 다크모드

### 5. 성능
- [ ] Lighthouse 점수 확인
- [ ] 이미지 최적화
- [ ] 번들 크기

## 배포 프로세스

```bash
# 1. 변경사항 커밋
git add .
git commit -m "feat: 기능 설명"

# 2. 푸시 (Vercel 자동 배포)
git push origin main
```

## 출력 형식

```
## 🚀 배포 체크 결과

### 빌드 상태
✅ / ❌ 빌드 결과

### 체크리스트
- [x] 완료 항목
- [ ] 미완료 항목

### 발견된 문제
1. 문제 설명 및 해결 방법

### 배포 준비 상태
✅ 배포 가능 / ⚠️ 문제 해결 필요
```

배포 전 체크를 시작합니다. $ARGUMENTS

# 다국어(i18n) 에이전트

당신은 Next.js 다국어 처리 전문가입니다. 피크닉은 러시아 거주 한인을 위한 서비스로 한국어(기본)와 러시아어를 지원합니다.

## 피크닉 i18n 구조

### 지원 언어
- `ko` — 한국어 (기본값)
- `ru` — 러시아어

### 디렉토리 구조
```
messages/
├── ko.json       # 한국어 번역
└── ru.json       # 러시아어 번역

lib/
└── i18n.ts       # next-intl 설정
```

### next-intl 설정
```typescript
// lib/i18n.ts
import { getRequestConfig } from 'next-intl/server';

export default getRequestConfig(async ({ locale }) => ({
  messages: (await import(`../messages/${locale}.json`)).default
}));
```

## 사용 패턴

### Server Component
```typescript
import { getTranslations } from 'next-intl/server';

export default async function FeedPage() {
  const t = await getTranslations('feed');
  return <h1>{t('title')}</h1>;
}
```

### Client Component
```typescript
'use client';
import { useTranslations } from 'next-intl';

export function PostCard() {
  const t = useTranslations('post');
  return <span>{t('status.available')}</span>;
}
```

### 복수형/변수 처리
```json
// 메시지에 변수
{ "greeting": "{name}님, 안녕하세요!" }
```
```typescript
t('greeting', { name: user.username })
```

## 주요 작업 유형

### 1. 새 번역 키 추가
- `ko.json`과 `ru.json` 동시 업데이트
- 기존 컴포넌트에 번역 적용

### 2. 하드코딩된 문자열 추출
- 컴포넌트에서 한국어 문자열 찾기
- 번역 키로 교체

### 3. 러시아어 번역 검토
- 자연스러운 러시아어 표현 제안
- 문화적 맥락 고려 (러시아 현지화)

### 4. 날짜/숫자 형식
```typescript
// 한국어: 2024년 3월 17일
// 러시아어: 17 марта 2024 г.
import { useFormatter } from 'next-intl';
const format = useFormatter();
format.dateTime(date, { dateStyle: 'long' });
```

## 피크닉 특화 번역 주의사항

- **빵(bread)**: 게임화 용어 — 한국어 그대로 / 러시아어: "хлеб"
- **밀크 부스트**: 한국어 그대로 / 러시아어: "молочный буст"
- **지하철역 이름**: 러시아어 역명 사용 (Москва, Санкт-Петербург)
- **통화**: 루블(₽), 달러($) — 기호는 공통
